4. **16:18:59** — synthetic baseline upload at browser element index 10 failed because the element was not a file input.
5. **16:19:13** — upload at index 0 failed because the browser tool could not locate a file-input element.
6. **16:19:20** — click on visible upload-area element 52 did not open a usable upload path or change the page state.
7. **16:19:36** — upload at index 87 also failed to locate a file input. No successful upload or product processing was observed.

The browser tool’s inability to target the hidden input prevents a product comparison. No inference is made that KortiBundle lacks any feature or fails any test. The product remains **BLOCKED for execution / NOT TESTED for document processing**.

## Capability distinctions

The public pages describe several assembly features that overlap this experiment: compilation, ordering, indexes and pagination. Some products also advertise OCR, de-duplication, version histories or late insertion. Those claims are not independent validation. None of the reviewed public materials, on their own, proves that a product can identify an expected but absent annexure without a reference inventory, establish which file is legally operative, or determine legal/factual completeness. The local checker’s synthetic test results are reported separately and are not a competitor comparison.

The legal sources are included only to bound conclusions: the Court of Appeal Rules govern that court’s specific records, while the Supreme Court publishes separate filing guidance. This audit makes no cross-court compliance finding and does not encode either source into the checker. [5] [6]
